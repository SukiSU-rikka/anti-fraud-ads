# 开屏跳过与启动弹窗的内置规则（随模块更新）。
# 自己的规则写在「设置页 → 规则 → 弹窗规则」，或 /data/adb/afa/rules/popup.txt，保存即生效。
#
# 写法：类型: 词1, 词2, …        前面加 @包名 只对那个应用生效；前面加 - 表示删除这条
#   跳过      开屏按钮的文字（包含即可，12 个字以内）
#   非广告    含这些字的「跳过」不是广告（视频跳过片头等）
#   拒绝      弹窗里的拒绝按钮，文字完全相同才点（页面和弹窗都点）
#   弹窗关闭  只在浮层弹窗里点的按钮（页面里的同名按钮是正常功能）
#   通知拒绝  只在「要通知权限」的弹窗里点
#   通知提示  弹窗里有这些字，就算「要通知权限」的弹窗
#   不碰      弹窗里有这些字，整个弹窗都不点
#   图标      没有文字的关闭图标，资源名包含这些字（只在浮层弹窗里点）

跳过: 跳过, 跳過, skip
非广告: 片头, 片尾, 片頭, 片段, 引导, 引導, 教程, 本集, intro, recap, 此步, 这一步

拒绝: 以后再说, 下次再说, 稍后再说, 稍后提醒, 下次吧, 以后吧, 暂不开启, 暂不打开, 暂不需要, 暂不更新
拒绝: 暂不升级, 暂不领取, 暂不参与, 暂时不用, 暂时不要, 暂不, 不再提醒, 不再提示, 不再显示
拒绝: 残忍拒绝, 狠心拒绝, 忍痛拒绝, 我再想想, 先不了, 先不用, 不用了, 不了谢谢, 不感兴趣
拒绝: 放弃领取, 放弃福利, 我知道了, 知道了, not now, later, no thanks, maybe later
弹窗关闭: 关闭, 关闭弹窗, ×, ✕, ✖, x, close
通知拒绝: 取消, 拒绝, 不允许, 禁止
通知提示: 通知, 推送, 消息提醒, 开启提醒, 提醒我, notification
不碰: 隐私, 协议, 政策, 条款, 同意, 授权登录, 实名, 支付, 付款, 扣款, 订阅, 续费
不碰: 删除, 清空, 注销, 退出登录, 卸载, 格式化, privacy, terms, agree
图标: close
