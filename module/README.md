# 反诈屏蔽 + AdGuard 去广告（一加 Ace 6 / ColorOS 17）v7.9

## 功能
- 内置 AdGuard Home v0.107.79（官方二进制，启停逻辑参考 twoone3/AdGuardHomeForRoot）
  - 默认订阅：AWAvenue 秋风广告规则（每 24 小时自动更新）+ 反诈屏蔽（模块内置本地规则）
  - DNS 劫持只在 AdGuard 真正监听后才生效，启动失败不会断网
  - 拦截 853 端口 DoT、拒绝 IPv6 DNS，防止绕过
  - 后台 http://127.0.0.1:3000 ，默认 root / root
- 反诈：按 UID 断开手机管家、appdetail、安全守护、反诈中心 App、安装器联网（IPv4+IPv6）；DROP 反诈 IP 与 ColorOS 云查杀 IP；封锁腾讯 HTTPDNS
- 冻结 com.oplus.thirdkit、com.opos.ads；锁定广告缓存（卸载自动还原）
- 挂起快应用本地服务、快应用卡片（可选：锁屏杂志），取自 android-ad-cleaner 在 ColorOS 17 上的实测；
  负一屏快递依赖的快应用平台、安装收尾页等会出问题的包永远不碰
- 开屏广告自动跳过（需要 Zygisk Next + GitHub 编译版）：只对选中的应用生效，应用打开第一个页面后几秒内
  找到「跳过」就点掉；其他应用启动时 Zygisk 库立即卸载，不留任何代码
- 「打开」：设置页（WebUI）—— 状态、拦截测试、全部开关、断网/冻结/域名名单、修改 AdGuard 密码、日志
- 「执行」：检查并修复状态，然后打开 AdGuard 后台；在管理器里关闭模块开关即暂停全部功能（立即生效）
- 反诈域名三层拦截：AdGuard DNS + SNI/Host 匹配（不依赖 DNS，开 VPN 也有效）+ IP

## 规则热更新
- 规则来源：内置（随模块更新）+ 我的规则（/data/adb/afa/rules/，更新模块保留）+ 订阅（rules/subs.txt）
- 格式自动识别：纯域名 → 拦截域名（SNI，并自动生成 DNS 规则）；||域名^ 等 → AdGuard DNS 规则；IP/网段 → IP；@@||域名^ → 放行
  也可用 [sni] [dns] [ip] [allow] 分区强制归类；# 和 ! 开头为注释
- 生效方式：只重建 SNI/IP 两条子链（毫秒级）；DNS 规则有变化时 AdGuard 重载约 2 秒（期间 DNS 直连，不断网）
- 放行名单优先级最高：被放行的域名不会被 SNI 拦截，AdGuard 中强制放行
